## v2.0.0-alpha-1

first alpha for v2 — mostly a big stability pass plus an early WIP branding customizer.

**what's new**
- **live customizer (WIP):** repurposed the old chat panel into a Customizer where you can edit menu/about/watermark titles, branch, dates, and profile labels live (auto-saves to the local server)
- **custom branding API:** added `/api/settings` and `/api/avatar` endpoints on the server

**fixes & cleanup**
- fixed CS:GO crashing on exit by properly unhooking Detours/VEH and cleaning up shutdown trampolines
- fixed Lua/libcurl HTTP requests getting caught by the `getaddrinfo` redirect
- defused the delayed anti-crack `Release()` time-bombs and cleaned up internal hooking/PEB patching
- tightened up the injector (safer version rewrite, SteamPath check, cleans up `steam_appid.txt` after injecting)
- hardened local server storage with atomic writes, `state.json.bak` recovery, proper trash/restore, and cleaner language file / `/api/reqitem` handling
